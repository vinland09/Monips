# MonitorIPs

MonitorIPs é uma aplicação para monitoramento de endereços IP em redes locais ou remotas.  
MonitorIPs is an application for monitoring IP addresses on local or remote networks.

## Funcionalidades / Features

- Monitoramento contínuo de IPs  
    Continuous IP monitoring
- Alertas em caso de indisponibilidade  
    Alerts in case of unavailability
- Relatórios de status  
    Status reports

## Instalação / Installation

1. Clone o repositório / Clone the repository:
        ```bash
        git clone https://github.com/seu-usuario/MonitorIPs.git
        ```
2. Instale as dependências / Install dependencies:
        ```bash
        cd MonitorIPs
        # Exemplo para Python / Example for Python
        pip install -r requirements.txt
        ```

## Uso / Usage

Execute o monitor / Run the monitor:
```bash
python monitor.py
```

Configure os IPs a serem monitorados no arquivo `config.json`.  
Configure the IPs to be monitored in the `config.json` file.
